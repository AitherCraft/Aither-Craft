# AitherCraft Dashboard

## Purpose

The AitherCraft Dashboard is a web control panel for managing the Minecraft server.

It allows administrators to:

- Start the server
- Stop the server
- Restart the server
- View server status
- View players
- View console logs
- Create backups
- Manage plugins
- Control settings
- Use Felix AI assistant

---

# User Access

Dashboard users:

## Owner
Full access:

- All settings
- Server controls
- Admin management

## Admin
Can:

- Manage server
- View logs
- Manage players

## Moderator
Can:

- Manage players
- View limited information
