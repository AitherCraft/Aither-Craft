# AitherCraft Phase 1 - Paper Server

## Goal

Create a working Minecraft Java server on a Windows PC.

## Requirements

- Windows 10 or Windows 11
- Java installed
- Paper server downloaded

## Server Folder

C:\MinecraftCrossplay

## Steps

1. Install Java.
2. Create the server folder.
3. Download the latest Paper server.
4. Rename it to paper.jar.
5. Place paper.jar into C:\MinecraftCrossplay.
6. Run start-server.bat.
7. Accept the EULA by changing:
   eula=false
   to
   eula=true
8. Run start-server.bat again.
9. Join from Minecraft Java Edition.
10. Verify the server is working.
