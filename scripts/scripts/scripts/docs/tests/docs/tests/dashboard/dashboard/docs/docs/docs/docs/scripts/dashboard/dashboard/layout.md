# AitherCraft Dashboard Layout

## Goal

Design a simple dashboard that works on:
- Phone
- Tablet
- Computer

## Main Screen

Top:
- AitherCraft logo
- Server status

Status Card:
- Online / Offline
- Player count
- Version
- Uptime

## Controls

Large buttons:

[ Start Server ]

[ Stop Server ]

[ Restart Server ]

[ Backup World ]

## Players

Shows:

Username
Platform:
- Java
- Bedrock
- Education
- Eaglercraft

Actions:
- Kick
- Ban
- Whitelist

## Console

View:
- Live server messages
- Errors
- Warnings

## Settings

Manage:
- Server settings
- Plugins
- Permissions
- Backups

## Mobile Design

Must support:
- Touch buttons
- Small screens
- Secure login

## Future Features

- Dark mode
- Notifications
- Automatic backups
- Update manager
