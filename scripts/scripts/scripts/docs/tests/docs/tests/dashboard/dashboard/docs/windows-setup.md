# AitherCraft Windows Server Setup

## Goal

Run AitherCraft on a personal Windows PC.

## Server Location

C:\MinecraftCrossplay

## Requirements

- Windows 10/11
- Java installed
- Internet connection
- Enough RAM for Minecraft server

## Setup Steps

1. Install Java.
2. Create C:\MinecraftCrossplay.
3. Download Paper server.
4. Place paper.jar in the folder.
5. Run setup-server.bat.
6. Start the server with start-server.bat.
7. Accept the Minecraft EULA.
8. Test Java connection.
