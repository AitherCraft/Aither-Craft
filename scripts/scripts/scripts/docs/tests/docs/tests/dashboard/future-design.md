# AitherCraft Dashboard Design

## Goal

Create a web dashboard to control the AitherCraft server.

## Features

### Server Controls
- Start server
- Stop server
- Restart server
- View server status

### Player Management
- View online players
- Kick players
- Ban players
- Manage whitelist

### World Management
- Create backups
- Restore backups
- View world status

### Cross-Play Management
- Java status
- Bedrock status
- Education status
- Eaglercraft status

### Admin Security

Only approved admins can access.

Planned roles:
- Owner
- Admin
- Moderator

## Future Ideas

- Mobile dashboard
- Server logs viewer
- Automatic updates
- Plugin manager
