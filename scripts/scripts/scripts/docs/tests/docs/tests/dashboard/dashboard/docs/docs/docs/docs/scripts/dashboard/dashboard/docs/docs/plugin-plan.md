# AitherCraft Plugin Plan

## Goal

Choose server features while keeping the server fast, secure, and easy to manage.

## Core Server

Required:
- Paper
- Geyser
- Floodgate

Purpose:
- Java support
- Bedrock support
- Cross-play foundation

## Security Plugins

Planned:

- Permissions system
- Anti-cheat
- Login protection
- Backup tools

## Player Features

Possible:

- Homes
- Warps
- Player shops
- Chat tools
- Achievements

## World Features

Possible:

- Claims/protection
- Custom worlds
- Events
- Minigames

## Administration

Needed:

- Player management
- Logs
- Server monitoring
- Admin tools

## Performance

Rules:

- Avoid unnecessary plugins
- Test each plugin
- Keep backups before changes

## Future Ideas

- AitherCraft custom plugins
- Custom commands
- Dashboard integration
- AI helper tools
