# AitherCraft Backup Plan

## Goal

Protect the Minecraft world.

## Backup Location

C:\MinecraftCrossplay\backups

## Backup Schedule

Recommended:
- Before updates
- Weekly backups
- Before major changes

## Files To Protect

- world folder
- plugins folder
- configuration files

## Files NOT Stored on GitHub

- World data
- Player data
- Passwords
- Private keys
