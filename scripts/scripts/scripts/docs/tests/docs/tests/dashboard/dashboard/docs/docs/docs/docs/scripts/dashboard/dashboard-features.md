# AitherCraft Dashboard Features

## Goal

Create a secure web dashboard to control the AitherCraft Minecraft server.

## Login

Requirements:
- Admin login required
- No public access
- Permission levels

Roles:

Owner:
- Full control
- Manage admins
- Server settings

Admin:
- Start/stop server
- Manage players
- View logs

Moderator:
- Player management only

## Main Dashboard

Shows:

- Server online/offline status
- Player count
- Server version
- Memory usage
- CPU usage
- Recent logs

## Server Controls

Buttons:

- Start
- Stop
- Restart
- Backup
- Update

## Player Controls

Features:

- Online player list
- Kick player
- Ban player
- Whitelist player

## Cross-Play Status

Display:

- Java status
- Bedrock status
- Education status
- Eaglercraft status

## Security

Never store:

- Passwords
- Private keys
- World files

Keep secrets on the server computer.
