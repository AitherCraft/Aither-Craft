# AitherCraft Server Dashboard Roadmap

## Future Feature: Web Dashboard

A future AitherCraft dashboard will provide a control panel for managing the Minecraft server.

Planned features:

- Start and stop server
- View server status
- View player list
- Monitor Java, Bedrock, Education, and Eaglercraft connections
- View server console logs
- Manage backups
- Manage plugins
- View compatibility test status
- Server settings management
- Admin-only controls

## Security Goals

- Dashboard must require authentication
- Admin access only
- Never expose server credentials publicly
- Keep private server files outside GitHub

## Possible Future Technology

- Web-based interface
- Runs locally with the server
- Communicates with the Minecraft server safely
- Could support mobile control in the future

## Status

Planned for a later phase after the core cross-play server is working.
