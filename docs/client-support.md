# Client Support Plan

## Supported Clients

- Minecraft Java Edition
- Minecraft Bedrock Edition
- Minecraft Education Edition
- Eaglercraft 26.2
- Eaglercraft 1.8.8

## Planned Compatibility

Paper will be the main server platform.

Geyser/Floodgate will provide Bedrock compatibility.

Education Edition compatibility must be tested separately.

Eaglercraft compatibility requires investigation because it may require additional proxy or server software.
