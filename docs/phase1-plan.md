# Phase 1 — Paper Server Build

## Goal
Create the first working AitherCraft Minecraft server using Paper on Windows.

## Steps

- [ ] Install Java
- [ ] Create `C:\MinecraftCrossplay`
- [ ] Download Paper server
- [ ] Create startup script
- [ ] Accept EULA
- [ ] Start local server
- [ ] Join with Minecraft Java Edition

## Testing

The server must work locally before adding:

- Geyser
- Floodgate
- Bedrock support
- Eaglercraft compatibility

World files and private data stay outside GitHub.
