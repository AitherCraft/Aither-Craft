# AitherCraft Client Compatibility

## Goal

Track which Minecraft clients are supported and what software they require.

| Client | Planned Support | Required Software | Status |
|--------|-----------------|-------------------|--------|
| Java Edition | Yes | Paper | Planned |
| Bedrock Edition | Yes | Paper + Geyser + Floodgate | Planned |
| Eaglercraft 1.8.8 | Research | Compatibility bridge/WebSocket | Research |
| Eaglercraft 26.2 | Research | Compatibility bridge/WebSocket | Research |
| Minecraft Education | Research | Compatibility testing | Research |

---

## Java Edition

- Native support through Paper.
- Expected to be the primary platform.

---

## Bedrock Edition

Requires:

- Geyser
- Floodgate

Allows Bedrock players to join the Java server.

---

## Eaglercraft

Research items:

- Supported versions
- Authentication
- WebSocket requirements
- World compatibility
- Performance

---

## Minecraft Education

Research items:

- Connection compatibility
- Multiplayer support
- Authentication
- Feature limitations

---

## Compatibility Rules

A platform should only be marked as "Supported" after:

- Successful connection
- Gameplay testing
- Chat testing
- Block interaction testing
- Multiplayer verification
