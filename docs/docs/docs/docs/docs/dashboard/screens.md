# AitherCraft Dashboard Screens

## Goal

Design every screen that will be included in the AitherCraft Dashboard.

---

# 1. Login Screen

Displays:

- AitherCraft logo
- Username
- Password
- Sign In button

Only Owners and Admins can sign in.

---

# 2. Home Dashboard

Shows:

- Server Status (Online/Offline)
- Current Minecraft Version
- Players Online
- CPU Usage
- RAM Usage
- Uptime

Quick Actions:

- Start Server
- Stop Server
- Restart Server
- Backup Server

---

# 3. Players

Displays:

- Username
- Platform
  - Java
  - Bedrock
  - Eaglercraft
- Join Time
- Ping

Actions:

- Kick
- Ban
- Whitelist
- Send Message

---

# 4. Console

Displays:

- Live console output
- Errors
- Warnings
- Commands entered

Can filter by:

- Info
- Warning
- Error

---

# 5. Backups

Displays:

- Backup Name
- Date
- Size

Actions:

- Create Backup
- Restore Backup
- Delete Backup

---

# 6. Plugins

Displays:

- Installed plugins
- Version
- Enabled/Disabled

Actions:

- Enable
- Disable
- Check for updates

---

# 7. Settings

Displays:

- Server Name
- MOTD
- Max Players
- Difficulty
- Game Mode
- View Distance

---

# 8. Logs

Displays:

- Login history
- Admin actions
- Server events
- Error reports

---

# 9. Felix AI

Displays:

- Chat with Felix
- Server recommendations
- Performance suggestions
- Troubleshooting help

Examples:

"Restart the server."

"Show players online."

"Create a backup."

"Why is the TPS low?"

---

# Future Features

- Dark Mode
- Mobile-friendly interface
- Discord integration
- Remote access
- One-click server updates
- Live performance graphs
