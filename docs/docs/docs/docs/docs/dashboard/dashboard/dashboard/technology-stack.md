# AitherCraft Dashboard Technology Stack

## Goal

Choose the technologies used to build and run the AitherCraft Dashboard.

---

# Frontend (User Interface)

Purpose:

Creates the dashboard screens that admins use.

Planned:

- Web-based dashboard
- Works on phone and computer
- Responsive design

Possible technology:

- HTML
- CSS
- JavaScript

Future option:

- React or another web framework

---

# Backend (Server Control)

Purpose:

Connects the dashboard to the Minecraft server.

Responsibilities:

- Start server
- Stop server
- Restart server
- Read logs
- Create backups
- Manage settings

Possible technology:

- Node.js
- Python

---

# Database

Purpose:

Stores dashboard information.

Stores:

- Admin accounts
- Permissions
- Player records
- Logs
- Settings

Planned:

- SQLite for early versions

Future:

- PostgreSQL for larger servers

---

# Server Communication

Dashboard communicates with:

- Minecraft server console
- Server scripts
- Plugin APIs

---

# Security

Required:

- Password hashing
- Admin permissions
- HTTPS
- Secure sessions
- Activity logs

---

# Hosting

Initial plan:

Run on the same Windows PC as the Minecraft server.

Future:

Possible remote dashboard hosting.

---

# Future Features

- Mobile app
- Felix AI integration
- Discord notifications
- Multiple server support
