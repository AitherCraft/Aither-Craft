# AitherCraft EULA and Legal Notes

## Purpose

This document records the legal requirements and policies that apply to the AitherCraft server.

---

## Minecraft EULA

The server must follow Mojang's Minecraft End User License Agreement (EULA).

Before the server can start:

- Open `eula.txt`
- Change:

eula=false

to:

eula=true

This indicates that the server owner has accepted the Minecraft EULA.

## Repository Rules

GitHub is used for:

- Documentation
- Scripts
- Configuration templates

GitHub is NOT used for:

- World files
- Player data
- Passwords
- Private keys
- Server backups

---

## Community Rules

Players are expected to:

- Respect other players
- Avoid cheating
- Follow server rules
- Report bugs responsibly

---

## Privacy

Only collect information necessary to operate the server.

Do not share player information without permission.
