# AitherCraft Server Folder Structure

## Goal

Explain how the AitherCraft server will be organized on the Windows PC.

## Main Folder

Location:

C:\MinecraftCrossplay

---

## Server Files

C:\MinecraftCrossplay

Contains:

- paper.jar
- eula.txt
- server.properties
- start-server.bat
- stop-server.bat

---

## World Files

Location:

C:\MinecraftCrossplay\world

Contains:

- Minecraft world data
- Player data
- Region files

Important:

Do NOT upload this folder to GitHub.

---

## Plugins

Location:

C:\MinecraftCrossplay\plugins

Contains:

- Geyser
- Floodgate
- Other server plugins

---

## Backups

Location:

C:\MinecraftCrossplay\backups

Contains:

- World backups
- Configuration backups

---

## Logs

Location:

C:\MinecraftCrossplay\logs

Contains:

- Server activity
- Errors
- Debug information

---

## GitHub Repository

Stores:

- Documentation
- Scripts
- Configuration examples
- Plans

Does NOT store:

- World files
- Passwords
- Server secrets
- Private player data
